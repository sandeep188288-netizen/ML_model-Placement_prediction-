
# 🎓 Placement Prediction System

A Machine Learning web application built using Python and FastAPI to predict student placement outcomes from student-related information.

🚀 **Live Demo:** [Placement Prediction App](https://ml-model-placement-prediction-4.onrender.com/)

💻 **GitHub Repository:** [ML_model-Placement_prediction-](https://github.com/sandeep188288-netizen/ML_model-Placement_prediction-)

## 📌 About the Project

The Placement Prediction System integrates a trained machine learning model with a web application. Users enter the required student information through a web interface, and the backend processes the input to generate a prediction.

## ✨ Features

- Machine learning-based placement prediction
- FastAPI backend
- Interactive HTML, CSS, and JavaScript frontend
- Pre-trained model loaded using Joblib
- Feature-column information stored separately
- Deployed on Render
- Publicly accessible web interface

## 🛠️ Tech Stack

- **Language:** Python
- **Backend:** FastAPI
- **Server:** Uvicorn
- **Machine Learning:** Trained ML model
- **Model Loading:** Joblib
- **Data Processing:** Pandas, NumPy
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render
- **Version Control:** Git and GitHub

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/sandeep188288-netizen/ML_model-Placement_prediction-.git
cd ML_model-Placement_prediction-
```

### 2. Create a virtual environment

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
uvicorn app:app --reload
```

Open the application at:

http://127.0.0.1:8000/

FastAPI documentation, if enabled:

http://127.0.0.1:8000/docs

## ☁️ Deployment

The application is deployed on Render.

**Build Command:**

```bash
pip install -r requirements.txt
```

**Start Command:**

```bash
uvicorn app:app --host 0.0.0.0 --port $PORT
```
